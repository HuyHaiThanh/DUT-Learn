## Tiêu chí nghiệm thu

- `docker compose -f infra/docker-compose.yml up -d db` → healthy; `uv run alembic upgrade head` thành công trên DB trống.
- `uv run ruff check . ; uv run mypy app ; uv run pytest` đạt (backend).
- `npm run lint ; npm run typecheck ; npm test ; npm run build` đạt (frontend).
- Chạy API native, `GET /api/health` → `db: true`; nếu Ollama đang chạy trên host thì `llm: true`.
- **Kiểm chứng ADR-09**: từ một container trong mạng compose (ví dụ `docker run --rm --add-host host.docker.internal:host-gateway curlimages/curl -s http://host.docker.internal:11434/api/version`) ghi lại kết quả thật. Nếu thất bại, ghi lỗi và **không** tự đổi cấu hình Ollama trên host; đề xuất cách xử lý trong báo cáo.
- Không commit `data/`, `.env`, `node_modules`, `.venv`.
