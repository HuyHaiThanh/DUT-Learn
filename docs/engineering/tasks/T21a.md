## API

| Phương thức | Đường dẫn | Quyền | Ghi chú |
|---|---|---|---|
| POST | `/classes/{id}/practice` | lecturer | `{kind: 'mcq'\|'short', stem 1–5000, options?: string[2..6] (mcq, mỗi phương án 1–1000, không trùng), answer_key, explanation ≤ 5000, lesson_id?}`. `mcq`: `answer_key` là chỉ số hợp lệ dạng chuỗi. `short`: `options` null, `answer_key` là đáp án mẫu 1–5000. Tạo `origin=lecturer`, `status=draft` |
| GET | `/classes/{id}/practice` | member | GV: mọi câu (gồm `answer_key`, `explanation`, `origin`, `status`, `supersedes_id`), mặc định ẩn `retired` trừ khi `?include_retired=true`. SV: chỉ `published`, **schema riêng không có trường `answer_key`, `explanation`** (I5), kèm `my_attempts` (số lần) và `my_last_correct` (bool \| null) |
| PATCH | `/practice/{id}` | lecturer | câu `draft`/`approved`: sửa tại chỗ (câu `ai` đã `approved` mà bị sửa thì về `draft`). Câu `published`: tạo câu mới (`supersedes_id` = id cũ, `origin` giữ nguyên, `status=published`, `published_at` mới) và chuyển câu cũ sang `retired` trong cùng transaction; trả câu mới. `retired` → 409 |
| POST | `/practice/{id}/approve` | lecturer | chỉ `origin=ai` và `draft` → `approved` (ghi `approved_by/at`). Câu `lecturer` → 409 `invalid_transition` |
| POST | `/practice/{id}/publish` | lecturer | `lecturer`: `draft → published`. `ai`: chỉ từ `approved` (từ `draft` → 409, I6) |
| POST | `/practice/{id}/retire` | lecturer | `published → retired` |
| POST | `/practice/{id}/attempts` | student | `{response, idempotency_key}`. Chỉ câu `published` (khác → 404). `mcq`: `response` là chỉ số dạng chuỗi hợp lệ, còn lại 422; `is_correct` = so với `answer_key`. `short`: `response` 1–5000, `is_correct=null`. Lưu `question_snapshot` (`kind`, `stem`, `options`, `answer_key`, `explanation`). Trả `{attempt_id, is_correct, answer_key, explanation, submitted_at}`. Chống trùng `operation='practice_attempt'`. `record_event(practice_attempted, ref_type='practice_question')` |
| GET | `/practice/{id}/attempts/me` | student | các lần làm của chính mình (kèm đáp án và giải thích, vì đã nộp) |

Quyền và lỗi theo §4 như các module khác: không phải thành viên → 404, sai vai trò → 403, SV ở lớp `closed` → 404.

## Test bắt buộc (pytest)

1. **I5:**
   - response danh sách của SV không có khóa `answer_key`/`explanation`, kiểm cả JSON thô;
   - câu `draft`/`approved`/`retired` không xuất hiện với SV;
   - SV làm câu chưa công bố → 404.
2. **I6:**
   - câu `origin=ai` `draft` → publish trả 409;
   - approve rồi publish thì đạt;
   - sửa câu `ai` đã `approved` thì quay về `draft`.
3. **I7:** cùng key + cùng response → cùng `attempt_id`; khác response → 409.
4. **Chấm:**
   - `mcq` đúng/sai;
   - `short` cho `is_correct = null` và trả đáp án mẫu;
   - snapshot giữ đề cũ sau khi GV sửa câu (supersede).
5. **Quyền (I1):** SV lớp khác, GV lớp khác, admin không là thành viên → 404; SV gọi endpoint của GV → 403; `lesson_id` thuộc lớp khác bị từ chối.
6. Validate: `options` < 2 hoặc > 6, phương án trùng, `answer_key` ngoài khoảng → 422.
7. `practice_attempted` được ghi vào `learning_events`.
