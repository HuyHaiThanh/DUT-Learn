## Phạm vi

Chỉ sửa `apps/web/**`. **T06 sở hữu** `apps/web/package.json` và lockfile. Không sửa `services/**`.

## Yêu cầu

1. **Nền tảng UI**: Tailwind CSS 4 (plugin Vite), shadcn/ui (khởi tạo `components.json`, component đặt ở `src/components/ui`; chỉ thêm component dùng đến: button, input, label, card, dropdown-menu, avatar, separator, sonner/toast nếu cần). Alias `@/` → `src/`.
2. **Phong cách** (kế thừa prototype `demo/index.html` của dự án, không sao chép giao diện bên ngoài): nền giấy `#f6f7f2`, chữ `#172c3d`, phụ `#657687`, đường kẻ `#e2e8e5`, màu chính xanh `#167b69` (đậm `#0e5e50`, nhạt `#e9f4ef`), nhấn `#d7ed91`, cảnh báo `#b96d28`. Tiêu đề dùng serif (Georgia), nội dung sans (Inter/system-ui). Khai báo thành CSS variables/theme của Tailwind và token shadcn. Không chỉ dùng màu để thể hiện trạng thái.
3. **API client** `src/api/`: hàm `apiFetch` dùng `credentials: 'include'`, tự thêm `X-DUT-CSRF: 1` cho request ghi, parse lỗi `{error:{code,message,request_id}}` thành `ApiError`; kiểu dữ liệu viết tay theo hợp đồng (`Me`, `ClassSummary`).
4. **Xác thực**: TanStack Query `useMe()` gọi `/api/auth/me`; 401 → chuyển `/login` (giữ đường dẫn quay lại). Trang `/login`: email + mật khẩu, nhãn tiếng Việt, hiển thị lỗi `invalid_credentials` và `too_many_attempts` rõ ràng, nút có trạng thái đang gửi, Enter để gửi. Đăng xuất từ menu người dùng.
5. **Bố cục theo vai trò** (React Router):
   - Khung chung: thanh trên (tên sản phẩm DUTLearn, menu người dùng), điều hướng bên trái trên desktop, menu thu gọn trên màn hình ≤ 768 px.
   - `/` chuyển theo vai trò: sinh viên → `/hoc` (danh sách lớp của tôi từ `GET /api/classes`, trạng thái rỗng "Bạn chưa được ghi danh lớp nào"), giảng viên → `/giang-day` (lớp phụ trách), admin (`system_role=admin`) → `/quan-tri` (trang giữ chỗ: người dùng, môn, lớp — nội dung ở task sau).
   - Người dùng vừa là GV lớp này vừa là SV lớp khác: hiển thị cả hai mục điều hướng.
   - Trang 404 tiếng Việt; trạng thái đang tải và lỗi mạng.
6. **Khả dụng**: điều khiển có nhãn, focus thấy rõ, dùng được bằng bàn phím, không tràn ngang ở 360 px.
7. **Test** (Vitest + Testing Library, fetch giả lập): đăng nhập thành công chuyển đúng trang theo vai trò; hiển thị lỗi sai mật khẩu; 401 từ `/auth/me` chuyển về `/login`; request POST có header CSRF; trạng thái rỗng danh sách lớp.

## Nghiệm thu

`npm run lint ; npm run typecheck ; npm test ; npm run build` đạt (sandbox có thể chặn esbuild/Vitest — vẫn viết test, ghi rõ lệnh không chạy được). Không push, không merge.
